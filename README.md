I'm the **creator and maintainer of [Mandao](https://github.com/JuanGuzman-io/mandao)**, an open-source CLI written in TypeScript. It began as a way to improve my own development methodology and is available for other developers and teams to use.

Mandao structures AI-assisted engineering around **specifications, traceability, tests, independent review, and human approval** rather than relying on generated code alone.

- **Spec-driven workflows:** From project rules and user stories to specifications, implementation, verification, and delivery.
- **Agent collaboration:** Clear implementer and reviewer roles, with independent review when the configured harness supports it.
- **Quality by design:** TDD where applicable, acceptance criteria, automated checks, and evidence-based verification.
- **Multiple coding agents:** Workflows for Claude Code, Codex, OpenCode, and GitHub Copilot.
- **Continuous improvement:** Run metrics and proposed process refinements, subject to approval.

```bash
npx mandao@beta init my-project
```

**TypeScript · Node.js · CLI · AI Agents · SDD · TDD**

[**Explore the repository**](https://github.com/JuanGuzman-io/mandao) · [**View on npm**](https://www.npmjs.com/package/mandao)
